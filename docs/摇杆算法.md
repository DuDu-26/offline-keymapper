# WASD 摇杆算法

实现：`app/src/main/java/cn/offline/mapper/engine/JoystickTrajectory.java`（轨迹）和 `JoystickController.java`（按键状态）。

## 按键状态

- W/S、A/D 相互抵消，剩余轴仍有效，得到八个方向之一。
- 第一个方向键按下时，在摇杆中心附近按下触点（拟真、平滑模式下在半径 `startOffsetPx` 的圆内随机落点）。
- 换方向只更换目标点，不抬起手指；松开最后一个方向键时在当前位置抬起。
- 半径键：长按时或按下切换时使用 `radiusSwitchPercent` 指定的半径。

## 轨迹模型

手指位置被一个**临界阻尼弹簧**拉向目标点，每 8ms 更新一帧。使用闭式解推进，任意帧间隔都稳定，且不会冲过目标：

```
offset = position - goal
term   = (velocity + ω·offset)·dt
velocity' = (velocity - ω·term)·e^(-ω·dt)
position' = goal + (offset + term)·e^(-ω·dt)
ω = 5 / 到位时间
```

位置和速度在换方向时延续，因此转向会自然划出弧线。

目标点 = 中心 + 方向 × 半径 × (1 + 推出比例)。

| 模式 | 目标 | 运动 | 按住时 |
|---|---|---|---|
| 拟真（默认） | 偏角在范围内随机，半径 ±5% 随机 | 弹簧 + 起步时少量横向速度 | 目标叠加两路平滑值噪声（每 260～380ms 一个随机节点，smoothstep 插值），幅度 `wobblePx` |
| 平滑 | 偏角取范围中值 | 弹簧 | 到位后停止发送 |
| 直接 | 同平滑 | 一次 MOVE 到位 | 无 |

只在取整后的坐标变化时发送 MOVE，坐标裁切在屏幕内。

## 参数

| 字段 | 含义 | 范围 | 默认 |
|---|---|---|---|
| `trajectoryMode` | 0 拟真 / 1 平滑 / 2 直接 | 0～2 | 0 |
| `settleMs` | 到位时间 | 10～500 | 拟真 70，平滑 60 |
| `wobblePx` | 按住漂移幅度（仅拟真） | 0～40 | 4 |
| `overshootPercent` | 终点超出半径的比例 | 0～100 | 拟真 15，平滑 10 |
| `startOffsetPx` | 按下起点随机偏移 | 0～60 | 20 |
| `customAngles` / `angleMin` / `angleMax` | 终点偏角范围（度） | -45～45 | -8～8 |

1.1.x 的旧配置可直接加载：`trajectoryVariant` 被忽略并移除，超过 ±45° 的偏角被收到 ±45°。旧的“全摇感 / 半摇感 / 普通”依次对应拟真 / 平滑 / 直接。

## 测试

`scripts/test-trajectory.sh` 在普通 JVM 上运行，使用假时钟，覆盖：直接模式落点、平滑模式到位时间与无过冲、转向连续、拟真漂移与偏角范围、可复现性、屏幕裁切、中断后不再发送。
