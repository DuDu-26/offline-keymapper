# 明天的 APK 验收说明

交付：`outputs/离线键鼠映射-v1.0.0-root.apk`。这是独立核心映射版，尚未达到原软件全部功能等价。支持 Android 9+，优先为已安装 SU 管理器的 Root 手机使用。

## 操作顺序

1. 安装 APK，打开“设置 → 请求 Root 授权并启动”；在 SU 管理器允许该应用。
2. 允许悬浮窗，连接 USB OTG 或蓝牙键鼠。状态须实际显示“Root 已激活”，不能只看授权弹窗。
3. 打开触控练习场，点击悬浮球“编辑屏幕点位”。确认方向摇杆、视角和按键中心位置，保存。
4. 开始映射。按 W+A 检查斜向，按 F1 锁定视角后移动鼠标，按住左键及空格检查多指。松开按键后所有对应触点应释放。
5. F1 解锁后鼠标应能移动指针并普通点击；滚轮可普通滚动。F8 应立即暂停映射、释放键鼠。
6. 添加游戏并打开，调整点位后在游戏中重复以上步骤。默认模板是通用布局，不能替代具体游戏的位置配置。
7. 导出 JSON、新建配置、导入，检查名称、坐标和动作一致；导出不会改变当前配置。
8. 映射过程中拔掉键鼠，应安全暂停；重新连接后用悬浮球开始。退出悬浮球后键鼠应恢复正常。
9. 横竖屏切换后检查点位；本版旋转会重新加载配置并暂停，确认布局后重新开始。

## 已验证和未验证

所有实测证据保存在 `outputs/` 和 `research/`，最终构建的哈希及摘要见 `outputs/交付校验.json`。

本机模拟器可以验证 UI、配置存储、Root daemon、合成 USB evdev、触控注入和状态机。它不能替代手机上的 SU 弹窗授权、KernelSU/Magisk 的 SELinux 上下文、蓝牙/USB 实物、具体游戏对输入的接受、120Hz/高回报率延迟或长期稳定性。

原软件的复杂宏、PUBG/姿态/武器/倍镜图像识别、压枪、手搓模式、云端配置与分享码、直接写触屏驱动未实现。本版不需要原软件鉴权服务，不具有原激活码或分享码兼容性。

## 常见问题

- Root 启动失败：在 SU 管理器检查是否允许本应用，查看本机“设置 → 查看诊断”。未经 Root 的手机无法使用本版输入引擎。
- 显示未发现可独占设备：当前引擎只抓 USB/蓝牙字母键盘和相对鼠标，触屏、电源/音量节点不会被抓。重新连接键鼠后刷新并开始。
- 系统拒绝注入/设备独占失败：本版会暂停并显示错误；保留诊断日志用于目标手机兼容性修复。不会自动更改 SELinux 或系统安全设置。
- 自由指针/射击：启用 FPS 视角时，F1 解锁后鼠标用于普通指针点击；锁定后鼠标按钮执行游戏触控绑定。
- 灵敏度：0.05～30；闲置释放 0 表示只在区域边缘抬起重定位。
- 编辑器按钮较多：工具条可水平滚动，设置表单可垂直滚动。完成/取消固定显示，退出编辑后才开始映射。
