# 第三方说明

- REA（morluto/rea，MIT）：本机静态分析工具，未打包进运行 APK。
- JADX / Apktool：本机静态调研工具，未打包进运行 APK。
- KeySync（aka-munan/keysync，Apache-2.0）：公开技术参考；未复制其应用代码、图片、图标、随机触控或反检测逻辑。标准 Gradle wrapper 文件取自该项目，Apache-2.0 全文随源码保留。
- Android SDK / Gradle / Android Gradle Plugin / NDK：构建工具，运行 APK 不依赖它们联网。
- 独立 Java 界面、JNI evdev 输入捕获、状态机和矢量图标为本项目新实现。

原始参考 APK 和 REA 的可读方法输出仅保存在本地研究目录，不包含在源码交付压缩包中。

WASD轨迹生成器依据用户提供APK的实际字节码、指令与隔离运行证据重建；原应用的权利归其权利人。交付源码不包含原APK、提取DEX、原图片/商标、原账号或付费授权实现。研究用Frida、只读内存采集器和原字节码oracle不进入运行APK。
