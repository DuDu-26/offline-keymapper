# 输入采集与鼠标修复（1.1.4）

现场已确认的1.1.3失败是鼠标内核队列溢出SYN_DROPPED；设备节点和Root进程仍存在，程序因此暂停并释放独占。此前还修复过读取预算耗尽被误当作断开的错误。

REA恢复原实现：EVIOCGRAB独占输入；native采集线程请求nice=-20，每就绪节点每轮最多64个事件；采集与最终触控处理通过共享ring分离。自由模式自绘光标，左键产生SOURCE_TOUCHSCREEN触控，未见逐样本系统HOVER注入。原ring满会丢帧，未发现键鼠SYN_DROPPED重同步，不能将这些弱点描述为自愈能力。

本地实现采用专用native捕获线程、有界用户队列、连续XY合并（保留按键/滚轮边界），锁外poll、fd与身份复核、扫描和诊断序列化移出捕获锁。真正丢事件或队列满仍明确暂停。停止时释放独占并回收线程；会话代际隔离旧输入。指针采用触控点击、独立帧回调和末坐标补发。WASD轨迹算法未改动。

验证：生产native假内核I/O测试覆盖48,000事件在消费者停顿时的位移及按键边界、队列容量、失联、SYN_DROPPED、线程启停与优先级成功/失败；引擎回归、三架构构建、Release/Lint、签名和16KB对齐通过。真机已确认采集线程实际nice=-20，1.1.4安装包字节一致。用户练习场实测反馈暂时正常、不再断开；游戏和长期稳定性未据此宣布全面通过。
