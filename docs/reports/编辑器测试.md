# 悬浮球与屏幕编辑器现场验证

验证日期：2026-10-13。设备：Android API 33 arm64 模拟器（运行时 API 经主线现场核实；compileSdk/targetSdk 为 35） `emulator-5554`，物理屏幕 1080×2400，密度 420dpi。验证构建：`app/build/outputs/apk/debug/app-debug.apk`。原生 Java，无 AndroidX 或外部 UI 依赖。

## 已通过

- `:app:compileDebugJavaWithJavac`、`:app:assembleDebug` 通过，最后一次构建日志 `research/editor-build.log`。
- 竖屏全屏编辑层窗口 frame `[0,0][1080,2400]`；横屏旋转后 frame `[0,0][2400,1080]`，全屏宽高与持久化归一化坐标一致。窗口位置、尺寸来自现场 `dumpsys window windows`。
- 游戏/练习场可以作为透明编辑层底图；按键、方向摇杆和鼠标视角可见；完成保存和取消按钮固定可见，其他工具横向滚动。
- 添加第 6 个点位默认选择空闲 E；不与模板 LMB/RMB/空格/R/SHIFT/WASD/F1 冲突。最多 20 个点位，复用空闲 ID，F8 保留。
- 输入框聚焦后 `input keyevent 35` 捕获为 G（Linux code 34）；按“应用”后保存的 label/code 为 G/34。
- 软键盘展开时设置对话框自动缩短，`应用`/`取消`按钮保持在键盘上方，字段可以滚动。现场 XML 的应用按钮 bounds 为 `[848,1322][1016,1464]`，键盘顶部在其下方。
- 拖动点位后完成保存，SharedPreferences 中 x/y 更新；ACTION_UP 也应用最终位置，避免仅保存最后一个 ACTION_MOVE 的滞后位置。横屏拖动保存为约 `x=0.40017,y=0.600015`（手指起点相对点位中心存在小量偏移）。
- 编辑后取消，存储 JSON 与上一次已保存 JSON 完全一致（`editor-cancelled-profile.xml` 与 `editor-captured-profile.xml`）。
- 未激活 Root 的情况下仍可完成本地保存，避免无连接 configure 把保存流程变成失败。
- 删除测试点位后恢复默认 5 个 bindings；原有坐标、joystick、aim 配置保留。测试结束恢复 `accelerometer_rotation=1`、`user_rotation=0`。
- 保存/取消之后只保留 137×137px 小球窗口，标记 `NOT_FOCUSABLE|NOT_TOUCH_MODAL`；全屏 editor/dialog 不再存在。交接时 TouchLabActivity 在前台。

## 发现并修复

1. targetSdk 35 的应用在 API 33 设备上使用 MATCH_PARENT overlay 时，现场观察到 `fitTypes=NAVIGATION_BARS CAPTION_BAR`、窗口高度 2337px，而物理屏幕高度为 2400px，造成全屏归一化偏差。系统栏适配是根据窗口属性作出的原因判断，未单独验证其全部触发条件。修为显式物理屏幕尺寸、API 30+ `setFitInsetsTypes(0)`，旋转时更新窗口尺寸；修复后现场 frame 为完整物理屏幕尺寸。游标和小球使用相同的全屏坐标设置。
2. overlay Dialog 使用固定高度时，软键盘遮挡底部应用按钮。修为按可见显示区域动态限制对话框高度。
3. 原横向工具条的保存/取消在竖屏末端不可见。移至固定头部。
4. 新点位原先固定空格键与模板冲突，改为优先 E，自动查找未占用键；点位 ID 复用空闲编号。

## 游标实现与验收边界

OverlayService 实现独立非触摸三角游标窗口：`NOT_FOCUSABLE|NOT_TOUCHABLE|NOT_TOUCH_MODAL`、窗口 alpha 0.65，随 RootBridge.cursorX/Y 更新；暂停、视角锁定、编辑层和设置对话框存在时隐藏。RootBridge 游标 API 已集成并通过编译。

本次编辑器 smoke 未验证真实 HID 事件→Root 读取→uinput 注入，也未独立实测运行中的游标/视角锁定状态。该设备已经交接 engine_review 进行全链路验证；物理手机、真实 USB/蓝牙键鼠与特定游戏仍属于后续真机验收。
