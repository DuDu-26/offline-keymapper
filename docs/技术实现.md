# 实现及验证边界

`MainActivity → ProfileStore / OverlayService → RootBridge → RootDaemon → MappingEngine → TouchInjector`。

SU 启动 `app_process`，Root 守护进程通过当前应用 APK classpath 加载独立 Java 引擎，native 库从系统安装后的 APK library 目录加载。服务只接受指定应用 UID 或 root 的本机抽象 Unix socket，随机 token 验证后才接受配置。没有 TCP 监听、网络权限或远程客户端。

JNI 使用设备 capability 和 USB/蓝牙 bus 识别字母键盘与相对鼠标。开始时 EVIOCGRAB，暂停/异常/断连时关闭或释放独占。触屏和独立 power 节点排除。键盘内电源/音量事件向 Android 转发，不能作为映射触发键。路径 inode 变化、POLLHUP 和 SYN_DROPPED 均触发取消触点与安全暂停。

所有触控共享一组 MotionEvent pointer 状态；DOWN/POINTER_DOWN/POINTER_UP/UP/CANCEL 使用当前索引和稳定 pointer ID。相同设备或多个设备的同一按键有独立持有状态；按下/释放时更新摇杆组合，斜向统一半径。事件时间使用真实 monotonic uptime，完整手势 downTime 一致。

配置按全屏比例保存，编辑层禁止默认系统栏裁切；旋转时按当前物理宽高重载并暂停。RootBridge 使用 generation 隔离旧启动/旧消息，关闭 socket 使 daemon 退出并释放输入；新配置失败必须先清除 configured 标志，不能启动旧布局。

自由鼠标使用 SOURCE_MOUSE 并维护 buttonState / actionButton；FPS 锁定后使用触屏指针滑动，闲置或边缘抬起释放再居中。自定义游标层不可触摸、alpha=0.65；运行时只保留小球，编辑全屏层始终移除。使用反射输入接口仅存在于 Root 守护进程，适配 InputManager / InputManagerGlobal；OEM 或未来 Android 的接口变化仍需现场测试。

README 中描述的功能均为独立实现范围。REA 看见的字符串不能当成完整算法或动态运行证据。

逻辑布局 ID（按键1～20、摇杆30、视角31）不直接发送给 Android。TouchInjector 为每个存活触点分配0～9的紧凑系统ID；释放其中一指后其余触点ID保持不变，空槽可被下一触点复用。此项已同时经过记录器和最终签名 APK 的真实四指注入验证。

三ABI native链接使用最大/常用页面16384，LOAD与GNU_RELRO的静态布局均已检查。此项依据 [Android 官方16KB说明](https://developer.android.com/guide/practices/page-sizes)，不代表已经在16KB真实设备运行。
